# 主动推荐信号治理

治理用户主动推荐信号，并据此审查创作者扶持与长期效果。

## 业务事实

- 平台已与数百个资源单位合作提供稀缺创作场景
- 参与者包括科研学者与多种小众职业创作者
- 优质内容会继续进入营销撮合与商业履约
- 推荐事件可能来自自然分享、活动任务、付费分发或异常协同

## 治理原则

- **事件留痕**：推荐发生时的作品版本、入口、观看深度、用户关系与撤销状态一并冻结保存。
- **重放不计数**：同一用户或同一设备对同一作品版本的重复推荐只计首条，其余作为协同证据留痕。
- **信号分账**：自然分享、活动任务、付费分发分别计量；扶持门槛只认自然分享信号。
- **风险只标记**：风险模型只产出待复核标记，确认/排除/申诉均由授权人员人工完成。
- **申诉恢复但不抹痕**：申诉成功恢复扶持资格，旧判断与冻结记录保留可追溯。
- **关系数据受限**：`relation_to_author` 及可定位关系的用户/设备标识仅 `risk_reviewer`、`auditor` 可查看，访问全部审计。

## 目录说明

- `contracts/domain.schema.json`：共享领域资料契约（作者阶段、稀缺场景等）。
- `contracts/timeline.schema.json`：治理时间线契约（事件、复核动作、回访）。
- `fixtures/context.json`：作者阶段（冷启动/成长/稳定）与稀缺场景公开资料。
- `fixtures/timeline.json`：脱敏端到端样例，覆盖自然分享、活动任务、付费分发、异常协同、重放、撤销与申诉。
- `src/`：治理服务模块。
  - `ingest.js` 不可变事件账本：幂等入库、用户/设备重放去重、按时点计算撤销。
  - `classify.js` 风险标记：短时密集分享、同设备多账号、异常低深度，只标记待复核。
  - `windows.js` 统计窗口：按渠道拆分自然/活动/付费与去重、撤销数量。
  - `review.js` 反作弊审查：建案、确认、人工排除、申诉推翻，结论只追加。
  - `eligibility.js` 扶持资格：分阶段门槛、违规冻结、申诉恢复。
  - `support.js` 扶持决策：发放时固化依据快照，并给出人读解释。
  - `effects.js` 效果回看：扶持前后持续创作与真实受众留存对比。
  - `privacy.js` 关系数据授权查看与访问审计。
  - `index.js` 编排门面：以判定时点重放整条流水线。
- `scripts/operator-report.js`：生成运营报告（一次扶持为何成立 + 前后效果对比）。

## 本地检查

```bash
npm test          # 32 个单元与端到端测试
node scripts/operator-report.js
```

样例中不包含账号、密钥、连接凭据或真实个人信息。

## 样例中的六位作者

| 作者 | 阶段 | 信号构成 | 结果 |
| --- | --- | --- | --- |
| 高原生态研究者阿青 | 冷启动 | 自然深度分享 | 获扶持，留存良好 |
| 非遗蜡染传承人次词 | 成长 | 活动任务 + 异常协同 + 大量真实自然分享 | 先冻结，申诉成功恢复 |
| 极地探险记录者吉冈 | 成长 | 付费加热为主 | 不获扶持（自然信号不足） |
| 深夜手工坊主老夜 | 冷启动 | 互助群协同刷量 | 风险确认，资格冻结 |
| 异宠科普者虫鸣 | 稳定 | 自然/活动/付费混合 | 不获扶持（稳定期门槛更高） |
| 水下考古学者陈眠 | 冷启动 | 自然分享为主，设备聚集存疑 | 风险标记待复核，不影响发放 |
